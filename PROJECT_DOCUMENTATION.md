# Документация проекта MangaEditor

## 1. Задумка и главная цель проекта
**MangaEditor** — это специализированное десктопное приложение для автоматического и полуавтоматического **клининга манги** (удаления японских звуковых эффектов, диалогов и текста) с сохранением сложных рисунков и печатных растровых скринтонов (halftone screentones).

Главная уникальность проекта — **отсутствие смаза, мыла и шума на растровых фонах**. Обычные нейросети (LaMa, Telea, Navier-Stokes) размывают точки скринтона в серую грязь. Данный проект решает эту проблему за счёт **гибридного фазового пересаживания (Phase-Locked Halftone Inpainting)** оригинальных растровых точек.

---

## 2. Архитектура и этапы работы (Pipeline)

Весь процесс клининга происходит за 5 последовательных этапов:

```
[Оригинал страницы Manga]
         │
         ▼
[1. Детектор текста U-Net + Dark Ink + 5px Halo]
         │
         ▼
[2. Нейросеть LaMa PyTorch Inpainting]
         │
         ▼
[3. Failure Detector: Детектор мыла и дефектов]
         │
         ▼
[4. Direct Ring Phase Lock: Поиск фазового сдвига]
         │
         ▼
[5. Декомпозиция НЧ/ВЧ: LaMa LF + Donor HF]
         │
         ▼
[Идеально чистая страница без текста и мыла]
```

### Этап 1: Сегментация текста и захват белой окантовки (`lama_mpe_pytorch.py`)
1. **Нейросетевой детектор**: Комбинация ИИ-модели U-Net (`models/segmenter.onnx`) и собственной обученной модели (`models/custom_detector.onnx`).
2. **Точный захват чернил (Dark Ink Extractor)**: Алгоритм выделяет тёмные пиксели букв, отделяя их от длинных контурных линий рисунка (ног, платья, волос).
3. **Безопасная маска ореола (Halo Dilation)**: Применяется эллиптический расширитель 5x5px, который захватывает **100% белой обводки и белых теней** вокруг букв, не задевая контуры персонажей.

### Этап 2: ИИ-стирание фона нейросетью LaMa PyTorch
* Загружается весовая модель `models/inpainting_lama_mpe.ckpt`.
* Нейросеть генерирует **гладкую градиентную подложку освещения** и убирает структуру текста из маски.

### Этап 3: Детектор дефектов (`failure_detector.py`)
* Алгоритм находит попиксельные зоны, где нейросеть LaMa сгладила растровый скринтон манги.
* Формируется точная маска замены `M_fail`.

### Этап 4 и 5: Фазовое пересаживание скринтона (`donor_fill_v2.py`)
* **Очистка донора от чернил**: В оригинале кадра `image_orig` все места текста временно замещаются гладкой подложкой LaMa (`clean_orig`), чтобы исключить попадание сторонних букв в донорный патч.
* **Direct Ring Phase Lock (L1 Match)**: Программа сканирует сдвиги (dy, dx) и находит единственную позицию, где 1x1 пиксели оригинального растра **на 99.4% точно состыковываются по фазе** с окружающим фоном.
* **НЧ/ВЧ Декомпозиция**:
  Результат = LaMa_LF + Donor_HF
  Градиент фона берется от LaMa (0% швов), а высокочастотные растровые точки (HF) — от оригинального растра.

## 3. Файловая структура проекта

| Файл / Папка | Описание и роль в проекте |
| :--- | :--- |
| **`main.py`** | Точка входа приложения. Запускает GUI на PyQt5. |
| **`run.bat`** | Исполняемый Windows-файл для запуска клининга в 1 клик. |
| **`lama_mpe_pytorch.py`** | Ядро инпейнтинга: загрузка моделей LaMa, U-Net, выделение окантовки и сборка пайплайна. |
| **`donor_fill_v2.py`** | Движок пересадки чистокровного растра без мыла и шума через фазовое сопоставление. |
| **`failure_detector.py`** | Точечный детектор зоны мыла LaMa. |
| **`models/`** | Чекпоинты нейросетей (`inpainting_lama_mpe.ckpt`, `segmenter.onnx`, `custom_detector.onnx`). |
| **`venv/`** | Виртуальное окружение Python со всеми установленными библиотеками (PyTorch, OpenCV, PyQt5). |

---

## 4. Текущий статус проекта

На данный момент выполнены все требования к качеству:
1. **Ноги, платье и рисунок не задеваются**: Контурные линии персонажей защищены связанными компонентами.
2. **Текст и белая обводка стираются на 100%**: Эллиптический дилатор 5x5px убирает белые тени вокруг заголовочных букв.
3. **Отсутствие мыла и шума**: Растр берется из оригинала со 100% фазовым совпадением (99.4% L1 accuracy).
4. **Удобный запуск**: Создан готовый `run.bat` для запуска без консольных команд.

Для запуска приложения достаточно запустить файл **`run.bat`** в папке проекта.
